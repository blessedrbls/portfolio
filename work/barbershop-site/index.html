01ЗадачаThe task

Барбершопу з двома філіями потрібен сайт, який за кілька секунд передає атмосферу, показує послуги, ціни й майстрів — і дає записатися, не дзвонячи, з гарантією, що обраний час справді вільний.A barbershop with two locations needs a site that conveys its atmosphere in seconds, shows services, prices and barbers, and lets people book without calling, knowing the chosen time is really free.

02Як це працюєHow it works

  1. 01

    Клієнт обирає послугу, майстра (або «будь-який»), філію, день на 2 тижні вперед і вільну годину.The client picks a service, a barber (or “any”), a location, a day up to two weeks ahead and a free hour.

  2. 02

    Cloudflare Worker перевіряє дані й зберігає запис у базі D1.A Cloudflare Worker validates the data and stores the booking in a D1 database.

  3. 03

    Заявка миттєво приходить у Telegram-групу адмінів з кнопками ✅ Підтвердити / ❌ Скасувати.The request lands instantly in the admins’ Telegram group with ✅ Confirm / ❌ Cancel buttons.

  4. 04

    Скасування в Telegram одразу звільняє час на сайті.Cancelling in Telegram frees the time on the site right away.

04Цікаві рішенняUnder the hood

Подвійний запис неможливийDouble booking is impossible

Унікальність слота гарантує сама база D1: двоє людей не займуть одного майстра на той самий час, навіть натиснувши кнопку одночасно.The D1 database itself guarantees each slot is unique, so two people cannot book the same barber at the same time, even if they press the button together.

Токен бота не потрапляє на сайтThe bot token never reaches the site

Сайт говорить лише з Worker-ом; токен і чат зберігаються як секрети на сервері. Worker приймає запити тільки з дозволених адрес і перевіряє кожне поле.The site only talks to the Worker; the token and chat id live as server-side secrets. The Worker accepts requests only from allowed origins and validates every field.

Без серверів і збіркиNo servers, no build step

Статичний сайт на GitHub Pages плюс безсерверний Worker — хостинг майже нічого не коштує й не потребує підтримки.A static site on GitHub Pages plus a serverless Worker: hosting costs next to nothing and needs no maintenance.
